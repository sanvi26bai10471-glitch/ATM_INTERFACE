# Universal ATM Interface System

A simple Python-based terminal ATM application that allows account authentication, cash deposit, withdrawal, balance check, dynamic user registration, and session transaction logs.

## 🚀 Features
* User Login with 4-digit PIN & security lockout
* Check Account Balance
* Cash Deposit & Cash Withdrawal with validation[cite: 1]
* View Session Mini-Statement[cite: 1]
* Dynamic New Account Registration[cite: 1]

## 🛠️ How to Run
1. Make sure Python 3.x is installed.
2. Open terminal/command prompt and run:
   ```bash
   python main.py
